三步完成接入

  1. 前往 caapi.top 注册账号，在控制台创建 API Key（sk- 开头）
  2. 在客户端或 SDK 中将接口地址设为 https://caapi.top/v1，并填入 API Key
  3. 从 模型列表 选择模型名，开始调用
